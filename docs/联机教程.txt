DNF 联机工具 V1.0 · 使用说明
==================================================================

这份说明只有三部分：房主怎么做、朋友怎么做、出问题看哪里。


一、房主（服务端在这台电脑上）
------------------------------------------------------------------

  第 1 步  连上网络
    打开 Radmin VPN，加入你们约好的网络（或自己建一个）。
    工具右上角出现 26.x.x.x 就是连上了。

  第 2 步  一键启动
    打开 DNF联机工具V1.0.exe → 选【我是房主】。
    点左边蓝色【一键启动联机】→ 弹窗问「要启动游戏吗」选【是】。
    工具会自己按顺序做完五件事（日志里逐行能看到 √）：
      hosts → 假人(./robot) → 虚拟机+服务端 → 端口转发 → 自检
    冷启动大约 40 秒，别急着点第二次。

  第 3 步  进游戏
    登录器弹出、显示「服务端已上线」→ 点【登录】→ 选频道 →【游戏开始】。

  然后把这个工具（同一个 exe）和你的 Radmin IP 发给朋友。


二、朋友（连到房主的电脑）
------------------------------------------------------------------

  第 1 步  装 Radmin VPN，加入房主给你的网络。
  第 2 步  打开同一个 exe → 选【我不是房主】。
          点【游戏路径】选你的客户端目录里的登录器 exe；
          点【房主 IP】填房主给你的 26.x.x.x（留空=自动查找）。
  第 3 步  点【一键启动联机】→ 它会自动改客户端配置 → 选【是】开游戏。
          登录器显示「服务端已上线」就说明连上了。

  账号：问房主要，或者在登录器里点【注册】自己建一个。


三、按钮是干嘛的
------------------------------------------------------------------

  【房主】
    一键启动联机 …… 一条龙开服（点它就行）
    启动游戏 ………… 提权打开登录器，工具自动缩到托盘
    一键检查状态 …… 五项自检，哪项红你就看日志那一行
    假人管理 ………… 原生面板：看假人列表/在线数，应用密钥、下载密钥、开关自动、上线/下线/清理
    市场 ………………… 假人市场面板：拍卖行/点券服务状态、补货、收菜、清库、拍卖守卫、内存补丁
    假人参数 ………… 可视化改 robot_config.ini（等级/职业/装备/摆摊/喊话/自动调度…）
    重新部署假人 …… 重新上传 robot、同步密钥（升级或装坏了用）
    市场 …………… 拍卖行/点券的补货、回收、清库、守卫（原生面板）
    重启拍卖 ……… 重启拍卖行(30803)+金币寄售(30603)，重建搜索索引（约 10 秒）
    拍卖设置 ……… 回收概率、价格浮动、分类单价（改完【保存并重建】生效）
    停止服务端 ……… 停服务端，顺带停假人（虚拟机不关，下次启动更快）
    停止端口转发 …… 关转发器
    修改联机 IP …… Radmin IP 变了以后点它，会自动改服务端 37 个配置 + 客户端
    设置客户端路径 … 指定客户端目录里的登录器（换启动器/版本都行）
    设置服务端路径 … 服务端文件夹搬家后重新指定 .vmx
    联机教程 ………… 把这几段文字显示在右边
    环境自检 ………… 看 .NET / Python / WinSCP / VMware / Radmin 是否齐全
    退出 ……………… 停服务端 + 停转发，等端口真正关闭再关闭工具

  【朋友】
    游戏路径 / 房主 IP / 一键启动联机 / 启动游戏 / 一键检查状态 / 联机教程 / 环境自检 / 退出


四、假人系统（可选，只有房主有）
------------------------------------------------------------------

  第一次开服时工具会问「要不要部署假人系统」：
    选【是】→ 先让你确认服务端信息（默认 <VM_IP> / root / <你的 SSH 密码>，
             和你登录服务端的一样），再让你确认客户端目录和部署包目录。
             确认后自动：上传 robot → 放配置 → 同步两个密钥到游戏服务端
             和你的客户端 → 启动假人。约 1~2 分钟。
    选【否】→ 不带假人，以后想用点【重新部署假人】。

  部署完打开【假人管理】（工具内原生面板，不需要浏览器/网页控件）：
    · 十张卡片：假人进程 CPU/内存、游戏端口 10011、在线上限（在线/目标）、
      上线中、引擎模式、服务 M/A/G/R、密钥状态、自动行为、摆摊、假人总数
    · 工具栏：刷新 / 自动开·关 / 上线 / 移动 / 喊话 / 摆摊 / 下线 / 清理 /
      参数 / 市场 / 密钥 / 诊断 / 网页版（网页版=用浏览器打开老网页，兜底用）
    · 表格：UID / CID / 名字 / Actor / 状态 / 等级 / 职业 / 城镇 / 区域 / 坐标 / 在线时长 / 摆摊
    · 每 5 秒自动刷新；【自动开·关】就是开/关假人自动上号
    · 【密钥】：选【是】=应用内置默认密钥；选【否】=把密钥下载到你本机客户端目录
      （等同以前用 WinSCP 手工拷 privatekey.pem / publickey.pem）

  【市场】面板（拍卖行 / 点券）
    · 四张卡：拍卖行服务 / 点券服务 / 上架种类 / 市场自动
    · 按钮：市场开始·停止、补货·拍卖 / 补货·点券、收菜·拍卖 / 收菜·点券、
      同步物品、清系统库存、拍卖守卫、内存补丁、网页版
    · 调试顺序（面板里也会提示）：先关自动 → 清库 → 重启 auction/point
      → 内存补丁 → 补货

  以前要手动做的三步（跑部署工具、WinSCP 拷密钥、网页点应用密钥），
  现在都在工具里了，不需要 WinSCP，也不需要浏览器。


  关于【假人参数】（改假人的细节行为）
    · 点左侧【假人参数】，工具会把服务端的 robot_config.ini 拉下来，
      按 10 个分组铺成表格：创建（等级/职业）/ 出生（城镇/坐标）/ 装备 /
      时装 / 宠物 / 摆摊 / 跟随 / 喊话 / 自动调度。
    · 每项下面那行小字就是这个参数的作用（和配置文件里的注释一致）。
      true / false 的项是勾选框，其它直接改值就行。
    · 改完点【保存并重启假人】→ 上传配置 + 重启假人，几十秒后生效；
      只点【仅保存】则下次重启假人才全部生效。原配置会自动备份成
      robot_config.ini.bak.日期-时间。
    · 常用项：自动调度里的 auto_target_online_count＝想保持多少个假人在线；
      创建里的 level_min / level_max＝假人等级范围；
      摆摊里的 store_equipment_intensify_min/max＝摊位装备强化范围。

  关于【重启拍卖】和「拍卖搜不到货」
    · 拍卖行服务启动时会把 auction_main 整张表读进内存做搜索索引；
      假人补货是直接往表里插，不会进这份内存索引 → 新补的货搜不到、
      「搜索出 0 个」就是没在索引里，不是数据库坏了。
    · 点【假人管理】→ 工具栏【重启拍卖】→【是】，约 10 秒，
      服务会重新读一遍 auction_main，新货立刻能搜到（玩家无感）。
    · 自动重启已经关掉了（2026-11-03 按你的要求移除 crontab 那条 */30），
      现在只有手动点【重启拍卖】才会重启；脚本本身保留在
      /root/restart_auction.sh，日志 /root/restart_auction.log。
    · 工具里也可以单独跑：scripts\dnf_auction_ctl.py restart / status。

  关于【市场】和【拍卖设置】（拍卖行相关）
    · 【市场】里能看到拍卖行服务 / 点券服务是否 ready、上架种类数、市场自动开关，
      下面 12 个按钮就是补货、收菜、清库、守卫、内存补丁这些操作。
    · 【拍卖设置】和网页端那个「拍卖」对话框一样：回收策略、价格浮动、
      装备/堆叠、11 个分类的单价范围。改完点【保存并重建】才会按新规则重挂商品；
      只点【保存】只写配置，下一次补货才用新规则。
    · 到底会不会回收玩家的货？会。条件是「玩家（或你自己）挂的一口价商品」，
      纯竞拍（没有一口价）的不收；假人自己的挂单也不会被回收。
    · 回收动作是假人系统的虚拟买家（uid 90100001 起）真的进拍卖行买下来，
      所以卖家的金币和邮件是拍卖行服务自己发的（写进 taiwan_cain_2nd 的 postal/letter 表），
      这也是为什么拍卖行必须先修好、月表必须存在。
    · 概率：价格落在范围内按「范围内回收概率」，超出范围按「范围外回收概率」，
      所以不是每件都收，这是设计如此（避免把市场扫空）。
    · 【清空库存】只清假人自己挂的（owner_id ≥ 90000001），不动玩家的货。

  关于喊话内容（假人自动喊的话）
    · 喊话内容在服务端 /root/config/templates/robot_shout_templates.json。
    · 工具自带的部署包已经内置了一份（假人部署包\config\templates\），
      每次点【重新部署假人】都会自动覆盖上去，不用再手动替换。
    · 想换内容：改 假人部署包\config\templates\robot_shout_templates.json
      （JSON 里 messages 数组，一行一条），再点一次【重新部署假人】。

五、环境要求
------------------------------------------------------------------

  · Windows 10 / 11（64 位），自带 .NET Framework 4.8
  · Python：房主端已自带（python 文件夹），不用另外装
  · VMware Workstation：只有房主要（起虚拟机）
  · WinSCP：不需要，工具内置传文件

  不确定缺什么？打开工具 →【环境自检】，红色的那项按提示装。
  这些运行库都在微软官网能下，工具不额外占空间。


六、文件夹里都有什么
------------------------------------------------------------------

  DNF联机工具V1.0.exe …… 主程序（房主/朋友都是它）
  启动器配置.ini ………… 你选过的路径和 IP，删了会重新生成
  python\ ………………… 房主端用的绿色 Python（朋友端用不到）
  scripts\ ……………… 9 个小脚本（改 IP / 起服务 / 部署假人 等）
  假人部署包\ …………… robot 程序、默认配置和喊话模板，部署时上传到服务端
  文档\ ………………… 就是本说明 + 快速开始.txt
  工具\ ………………… 安装/取消开机自启.bat


七、出问题先看这里
------------------------------------------------------------------

  1. 一键启动卡住 → 头一次开虚拟机慢，等 60 秒；还不行点【停止服务端】再点一次
  2. 朋友连不上 → 让他点【一键检查状态】；房主这边也要全绿
  3. 登录后进频道黑屏 → 服务端通告的 IP 不对，点【修改联机 IP】重跑
  4. 登录器白屏/一闪就没 → 一定要用工具里的【启动游戏】（会自动提权）
  5. 假人不上号 → Game port 是不是绿的？【密钥】里点了【应用密钥】吗？
  6. 换了网络/IP → 点【修改联机 IP】填新的，再把新 IP 发给朋友
  7. 拍卖行搜不到货 → 先点【一键检查状态】看 30803 / 30603 两个端口是不是绿的；
     绿了还搜不到，就在【假人管理】里点【重启拍卖】（重建搜索索引）
  8. 想彻底停掉 → 点左下角【退出】（房主会先停服务端和转发）

  关于拍卖行（说清楚原理，省得再折腾）
    · 游戏里拍卖行是客户端直连拍卖服务的，地址由服务端 cfg 下发
      （/home/neople/game/cfg/siroco*.cfg 的 auction_server_ip、
      cera_auction_server_ip），本工具已把它改成房主的 Radmin IP，
      并且转发器会转发 30803（拍卖行）和 30603（金币寄售）两个端口。
    · 所以：转发器必须开着；换 IP 时【修改联机 IP】会把这四个字段一起改。
    · 假人补货是直接写 auction_main 表，服务只在启动时读一次建搜索索引，
      所以新货要等【重启拍卖】（或每 30 分钟的自动重启）才搜得到。
